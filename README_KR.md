# 🚮 랜덤 포레스트와 공공데이터 분석을 활용한 전주시 쓰레기 문제 해결 방안 
> 제2회 전북 청년 빅데이터 경진대회 – *우리은행 은행장상* 수상 (2024년 12월)

📊 **주최**: 전북 빅데이터 기술교류 공동연구회, 우석대학교 LINC 3.0 사업단, 전북대학교 빅데이터 혁신융합대학 사업단

👩‍💻 **기획 및 분석**: 강민수, 이기백, 이혜원, 임정민

🗓 **프로젝트 기간**: 2024년 10월 1일 ~ 10월 4일

## 💬 1. 프로젝트 개요 
전주시 원룸촌과 주택가의 생활폐기물 분리배출 및 불법 투기 문제를 해결하기 위해 공공데이터 분석과 머신러닝을 결합한 프로젝트입니다. **재활용 정거장(Recycling Station)** 설치를 정책 대안으로 제안하고, **송천1동**을 중심으로 상세 입지를 분석했습니다.

원래 경진대회에서 제안한 구간은 **송천동2가 붓내5길~붓내3길 일대**입니다.

이 저장소에는 프로젝트 데이터, 과거 노트북, 빠진 분석 단계를 재구현한 코드가 포함되어 있습니다. 기존 분석 과정을 확인하고 재현할 수 있도록 정리했으며, 프로젝트 설명과 상세 분석 대상은 기존 송천동 제안을 중심으로 유지합니다.
<br/>
<br/>

## 🗑️ 2. 연구 배경 및 목적 
반복되는 불법 투기, 분리배출 장소의 접근성, 지정된 배출 일정, 감시와 안내문만으로 해결하기 어려운 문제를 고려하여 재활용 정거장 정책을 제안했습니다.

다음 내용을 중심으로 분석하며, 이러한 분석을 바탕으로 기존 재활용 정거장 제안과 송천동의 상세 공간 분포를 검토합니다.

- 전주시 행정동별 인구, 주택 분포, 불법 투기 단속 기록의 차이
- 행정동별 특성과 쓰레기 배출량 추정치 사이의 관계
- 송천1동의 주택·불법 투기 단속·음식점 위치 분포
<br/>
<br/>

## 🧩 3. 데이터 구성 
**주요 분석 단위**는 제공된 전주시 행정구역 경계의 **35개 행정동**입니다. 상세 지도는 송천1동과 붓내3길 ~ 붓내5길 일대를 중심으로 살펴봅니다.

| 데이터 | 활용 목적 |
|---|---|
| 전주시 인구·세대수 통계 | 행정동별 기초 분석과 모델 입력 |
| 주택 · 주거용 건물 · 오피스텔 현황 | 건물 분포와 행정동별 건물 수 집계 |
| 전국 시군구 쓰레기 배출량 자료 | 배출량 예측 모델 학습 |
| 불법 투기 단속 기록 | 단속 건수 및 발생 위치 확인 |
| 행정구역 경계(GeoJSON) | 행정동 지도와 좌표 분류 |
| 음식점 위치 자료 | 송천동 상세 지도에서 상업 활동 분포 확인 |
| 기존 예측값·집계 결과 | 기존 분석 재현을 위한 입력 |

전처리는 숫자형 필드 정리, 행정동 명칭 통일, 좌표의 행정동 분류, 결측값·중복 확인, 데이터 병합, Min–Max 정규화로 구성됩니다.

군집화에는 **건물 수, 단속 건수, 연간 쓰레기 배출량 추정치**를 사용합니다. 건물과 단속 변수는 면적당 밀도가 아닌 건수이며, 기존 ‘쓰레기 민원’ 컬럼은 단속 기록을 기반으로 합니다.

상업 활동 지도 재구현을 위해 공식 음식점 좌표 자료를 보완했습니다. 기본 자료의 기준일은 2022년 4월 1일이며, 2025년 6월 4일 자료도 보관되어 있습니다. 보완 자료가 당시 경진대회에서 사용한 음식점 자료와 동일하다고 단정할 수는 없습니다. 음식점 위치는 상업 활동의 일부를 나타내는 지표입니다.

출처와 처리 기록은 [데이터 출처 문서](docs/data_sources.md)와 [음식점 처리 기록](data/processed/commercial_provenance.json)에 정리되어 있습니다.

## 🔎 4. 분석 방법 

### 4.1 머신러닝 기반 쓰레기 배출량 예측
**랜덤 포레스트(Random Forest)**와 비교 모델인 **다층 퍼셉트론(MLP)**으로 연간 쓰레기 배출량을 추정합니다. 전국 시군구 자료의 인구수와 세대수를 입력으로 학습한 모델을 전주시 행정동별 입력에 적용합니다.

재구현한 학습 노트북에는 지역 그룹 단위 검증과 MAE · RMSE · R² 산출 과정이 포함되어 있습니다. 이 검증은 시군구 수준의 성능을 평가하며, 행정동 예측 정확도를 직접 측정한 것은 아닙니다.

문서에서 안내하는 재현 과정에서는 후속 분석에 **기존에 저장된 배출량 예측값**을 사용합니다.
<br/>

### 4.2 탐색적 데이터 분석(EDA) 및 PCA
- 행정동별 인구, 건물 수, 단속 건수, 배출량 추정치를 지도에 표시합니다.
- 군집화 변수에서 인구를 제외하기 전후의 상관관계를 확인합니다.
- PCA 설명 분산과 성분 계수로 정규화한 변수의 구조를 검토합니다.

현재 군집화 구현은 정규화한 세 변수를 직접 사용하며, PCA는 변수 구조를 살펴보는 진단 단계로 제공됩니다.
<br/>

### 4.3 군집화 분석
**K-means, PAM 방식 K-medoids, 가우시안 혼합 모델(GMM), 계층적 군집화**를 비교하여 비슷한 특성을 가진 행정동을 살펴봅니다. 실루엣 점수, K-means 관성(inertia), 메도이드 거리 진단을 통해 군집 수와 이상치를 검토합니다.
<br/>

### 4.4 송천동 상세 공간 분석
송천1동의 **주택 건물, 불법 투기 단속 위치, 음식점**을 상세 지도에 함께 표시합니다. 기존 제안 구간인 **붓내5길~붓내3길**을 중심으로 공간적 분포를 검토합니다.

재구현한 지도에서는 해당 도로명이 주소에 포함된 건물 범위도 확인합니다. 이 범위는 제안 구간을 살펴보기 위한 지리적 참고 영역이며, 측량된 설치 경계나 도로 중심선은 아닙니다.
<br/>

## 🌱 5. 기존 정책 제안 및 기대 효과

- 주민의 쓰레기 배출 편의 향상

## 💻 6. 분석 재현 방법 
Python 3.11 이상을 사용합니다. 저장소 최상위 폴더에서 필요한 패키지를 설치하고 Jupyter를 실행하세요.

```bash
pip install -r requirements.txt
jupyter notebook
```

`notebooks/`의 파일을 열고 셀을 위에서부터 실행합니다. 각 노트북은 파일에서 입력을 읽으므로 별도 커널에서도 실행할 수 있습니다.

| 순서 | 노트북 | 분석 과정에서의 역할 |
|---|---|---|
| 01 | [상권 좌표 전처리](notebooks/01_commercial_preprocessing.ipynb) | 음식점·주택·단속 좌표 정리 |
| 02 | [모델 학습](notebooks/02_model_training.ipynb) | 랜덤 포레스트·MLP 학습 과정 확인 및 실행 |
| 03 | [병합·정규화](notebooks/03_merge_normalize.ipynb) | 기존 예측값·집계를 병합하고 정규화 |
| 04 | [EDA·PCA](notebooks/04_eda_pca.ipynb) | 행정동 지도·상관관계·PCA 진단 |
| 05 | [군집화](notebooks/05_clustering.ipynb) | 군집화 방법 비교와 진단 |
| 06 | [송천동 입지 분석](notebooks/06_site_selection.ipynb) | 송천동 상세 지도와 기존 제안 구간 검토 |

ZIP에는 저장된 입력과 결과가 포함되어 있습니다. 저장소를 복제한 경우 원본 자료를 별도로 배치해야 할 수 있으므로 [데이터 출처 문서](docs/data_sources.md)를 확인하세요.
<br/>

### 송천동 중심 분석을 위한 설정
기존 분석 입력을 유지하려면 03번 노트북에서 다음 설정을 사용합니다.

```python
PREDICTION_SOURCE = 'saved'
COUNTS_SOURCE = 'saved'
```

06번 노트북에서는 다음과 같이 설정합니다.

```python
ANALYZE_AUTO_SELECTED = False
TARGET_DONG = '송천1동'
```

기존 제안 내용을 중심으로 확인하려면 **송천1동 상세 지도 셀**을 사용하세요. 노트북에는 추가적인 격자 후보 계산도 포함되어 있으나, 이는 보조 구현 결과이며 원래 경진대회의 입지 선정 결과로 인용하지 않습니다.

01번의 기본 설정은 `DATASET='historical_2022'`입니다. 기본 분석은 제공된 좌표를 사용하므로 지오코딩 API 키가 필요하지 않습니다. 인터랙티브 지도는 OpenStreetMap France / HOT 배경을 사용하며 인터넷 연결이 필요합니다.
