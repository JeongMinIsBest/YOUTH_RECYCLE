# 데이터 출처 및 배치

공식 음식점 좌표: https://www.data.go.kr/data/15076735/fileData.do

2021 음식점 메뉴 자료: https://www.data.go.kr/data/15097768/fileData.do

2022-04-01 파일은 위 좌표 데이터 페이지의 과거 이력, 2025-06-04 파일은 해당 시점 파일입니다.
분석 기본 자료는 2022년이며 최신 자료는 CLI 옵션으로 선택합니다.
그 밖의 자료는 사용자가 제공한 경진대회 ZIP에 포함된 파일이며 개별 원출처는 확보한 범위에서만 확인되었습니다.
원본 모델·집계 CSV와 GeoJSON도 재실행 입력이므로 함께 보존합니다.
자료별 이용 허락은 각 원출처에서 확인해야 하며 프로젝트에 일괄 라이선스를 부여하지 않았습니다.

## 생성 데이터와 결과

`data/processed/`는 전처리한 음식점·주택·단속 좌표 및 처리 기록입니다.
해당 노트북 실행 시 갱신됩니다. `commercial_provenance.json`에는 공식 원본 날짜와 SHA256이 기록됩니다.
`results/figures/`, `results/maps/`, `results/tables/`는 해당 분석 노트북 실행 시 갱신됩니다.
`index.html`은 제공 ZIP의 실행 결과를 보여 주는 정적 미리보기입니다. 설정을 바꾼 뒤의 결과는 노트북 또는 results 폴더에서 확인하세요.
