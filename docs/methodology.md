# 분석 방법과 해석


군집 우선순위는 세 정규화 변수(주택 수·단속 건수·배출량)의 동일 가중치 평균입니다.
이 새 규칙에서는 효자5동이 우선 대상입니다. PDF의 송천1동 선정 규칙을 복원한 것은 아닙니다.
군집 숫자 라벨은 임의적이므로 PDF의 '2번 클러스터'와 코드의 숫자가 같다는 이유로 같은 군집으로 판단하지 않습니다.

상세 입지 후보 점수는 100m 반경 내 주택·단속·음식점 개수를 각각 Min-Max 정규화한 뒤 같은 가중치로 평균한 값입니다.
지도에서 주황색 원은 새 규칙의 후보, 보라색 사각형은 붓내3길·5길 주소 건물들의 범위에 30m 여유를 더한 영역입니다.
보라색 사각형은 도로 중심선·정확한 설치 영역 또는 원본 분석 범위의 복원이 아닙니다.
토지 사용, 보행 접근성, 기존 시설과의 거리, 현장 설치 가능성을 포함한 확정 입지 선정에는 추가 검토가 필요합니다.

전국 시군구 검증 성능은 행정동 배출량 예측의 정확도가 아닙니다. 두 공간 단위의 인구 규모와 분포가 다릅니다.
배출량 단위/기준연도는 학습 CSV에 명시되지 않아 원 자료에서 확인해야 합니다.
기존 '원룸 및 주택 밀집'은 면적당 밀도가 아닌 건물 건수이고, '쓰레기 민원 빈도'의 입력은 실제로 단속/적발 데이터입니다.
단속 원본 1,202건 중 기존 좌표 결과는 1,144건입니다. 빠진 58건의 원본 처리 과정을 복원할 수 없습니다.
기존 단속 좌표에는 시외 지점이 포함되어 있습니다. 상세 지도는 행정동 경계로 재분류하고 제외 내역을 남깁니다.
행정동 군집화는 기본값에서 기존 저장된 집계를 유지합니다. 재집계 결과도 별도로 제공됩니다.
그림은 한글 폰트에 의존하지 않도록 영어/F1~F4 레이블을 사용하며 히트맵 한국어 대응은 *_legend.csv에 있습니다.
